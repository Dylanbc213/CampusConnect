# CampusConnect

Para reproducir videos dentro de las publicaciones instala VLC de 64 bits
(https://www.videolan.org/vlc/) y las dependencias de `requirements.txt`.
El reproductor integrado permite reproducir, pausar, detener y ajustar el volumen;
al abandonar la vista se detiene el video. No abre un reproductor externo.
Red social estudiantil con gestión de usuarios, amistades, publicaciones y persistencia en archivos
